## 1. 设计哲学与核心原则

针对原版本“视觉元素过多、高饱和色彩与阴影堆叠、缺乏呼吸感”的问题，本规范推倒重来，确立**极简主义（Minimalism & Swiss Style）**核心设计语言：

```
       [ 繁复的旧设计 ]                           [ 极简新规范 ]
 ┌─────────────────────────┐               ┌─────────────────────────┐
 │ 复杂渐变 + 粗厚彩色边框  │    ───► 削减    │ 单色极细边框 (0.5-1px)   │
 │ 霓虹发光 + 大面积重阴影  │    ───► 沉静    │ 自然柔和微阴影 / 纯扁平   │
 │ 常驻跳动大绿点 + 粗体徽章│    ───► 隐形    │ 等宽精密字符 + 静音指示点│
 │ 拥挤的顶部工具栏彩色按钮│    ───► 留白    │ 单色极简图标 + 悬浮响应  │
 └─────────────────────────┘               └─────────────────────────┘
```

### 五大核心法则

1. **绝对克制 (Radical Restraint)**
   - **界面颜色严格控制在 3 层**：背景底色（Canvas）、表面容器（Surface）、单一强调色（Accent）。
   - **摒弃装饰性渐变与荧光色**：不使用花哨的彩虹渐变和高光背景，界面的视觉权重完全由**字阶比例、留白（Negative Space）与线条密度**构建。
2. **静默智能 (Quiet Intelligence)**
   - 双网寻径（内网/外网）与延迟探测是插件的“核心技术肌肉”，但应当**以静默、精密的方式呈现**（如机械表的微雕刻度），而非全屏闪烁呼吸灯。
   - 默认状态下只展现纯粹的书签本体；当用户聚焦或悬浮时，才优雅透出网络拓扑与延迟数据。
3. **极速与键盘优先 (Frictionless Speed)**
   - 0 毫秒感知延迟，减少一切阻碍视线的层级遮挡。
   - 全键盘驱动（`/` 或 `Ctrl+K` 瞬间聚焦搜索，`Tab` / `↑↓` 快速选路，`Enter` 直达最优地址）。
4. **统一主题化与禁止使用原生组件 (Theme Harmonization & Zero Raw Native Elements)**
   - **组件深度融入主题**：所有 UI 交互元素（包括但不限于下拉框、单选/复选框、输入条、弹窗、Tooltip 气泡提示等）必须严格遵循当前激活的主题设计 Token，自适应亮色/暗色色彩系统。
   - **严禁使用未经主题美化的原生组件**：
     - 禁止使用原生浏览器提示（如 `title="..."` 原生 Tooltip），必须使用统一的浮层 Popover/Tooltip 胶囊。
     - 禁止使用未封装的原生 `<select>` 与原生滚动条/对话框，优先使用分段控件 (Segmented Control) 或主题卡片式下拉弹层组件。
     - 禁止使用原生 `alert()` / `confirm()`（危险操作优先采用应用内统一卡片弹窗或 Toast 确认）。
5. **容器尺寸恒定与禁止突兀形变 (Fixed Spatial Stability & Zero Layout Jitter)**
   - **同页面/同弹窗尺寸绝对恒定**：同一个弹窗（Modal）在不同 Tab 标签页切换、表单状态切换、异步加载中或展开子设置项时，**外部容器的宽度和高度必须严格保持一致**（统一使用 `h-[560px] flex flex-col` 等固定容器高度），严禁出现点击某个选项后弹窗整体尺寸突增/骤缩的跳动现象。
   - **内部溢出滚动治理**：内容量动态变化必须在内部 `flex-1 overflow-y-auto` 视口中优雅滚动消化，不得将尺寸抖动外溢给顶层容器或遮罩层。
6. **紧凑无滚动与视口自洽优先 (Compact Viewport & Zero Scrollbar Preference)**
   - **在控制总高度适中（不超过屏高 80%）的前提下，优先确保弹窗无需滚动即可一屏完整呈现所有核心信息与操作入口**。
   - **微距与留白精密排版**：通过合理的内边距（`p-2.5 ~ p-3`）、紧凑网格与精炼布局，使常规默认状态（如免 Key 3 步操作流、API 配置卡片）自然填满容器且不触发纵向滚动条；只有在超长列表展开或大量文本导入时，才自然触发内部局部滚动。

## 5. 核心组件精细化设计规范 (Component Specifications)

### 5.1 顶部静音导航条 (Top Navigation Bar)
- **视觉特征**：背景为极低饱和半透明底色，向下滚动时产生 `backdrop-filter: blur(16px)` 与 `1px solid var(--border-subtle)`。
- **Logo 区域**：去除复杂渐变背景，采用单色简约书签矢量图标 + `13px` Medium 灰度文字。
- **操作按钮**：
  - 去除厚重的大彩块。
  - 主要操作（“+ 添加书签”）：采用**高对比度小胶囊按钮**（浅色下为纯黑底白字，深色下为纯白底黑字，`h: 32px`, `px: 14px`, `rounded-full`, `text: 12px`）。
  - 次要操作（“导入”、“设置”）：采用**无边框纯图标/文字按钮**，悬浮时背景浅灰微亮，保持界面极度清爽。
  - 清空数据等危险操作：从顶栏移除，归入设置面板二级操作区。

---

### 5.2 极简中心搜索条 (Search Capsule)
- **形态**：单行极简胶囊，`h: 46px`，`rounded-full`。
- **边框与阴影**：
  - 默认态：`1px solid var(--border-subtle)`，背景为 `var(--bg-surface)`，无重投影。
  - 聚焦态：`1px solid var(--border-focus)`，轻微提升 `var(--shadow-md)`。
- **搜索引擎切换**：
  - 输入框左侧内嵌微型单色引擎 Icon（Google / 百度 / Bing / GitHub），点击原位滑出单色下拉面板。
- **右侧快捷键提示**：
  - 优雅的单色等宽小标签 `<kbd>⌘K</kbd>` 或 `<kbd>/</kbd>`，字号 `10px`，颜色 `--text-tertiary`。

### 5.3 签名级特色组件：精密寻径书签卡片 (The Precision Route Card)

这是整个界面的核心记忆点：**“外表极简克制，内里极具机械精密度。”**

#### A. 卡片外观解构 (Card Anatomy)

```
┌────────────────────────────────────────────────────────┐
│  [ 图标 ]  书签主标题                         [ ⋮ 更多 ]│
│  26x26    13px Medium 字重                   悬浮才显现│
│                                                        │
│  ● 10.8.0.52                                       4ms │ <- 等宽网络拓扑信息行
│  ↑                                                 ↑   │
│ 4px绿点(内网)                                  精确实测延迟 │
└────────────────────────────────────────────────────────┘
```

- **容器规格**：
  - 圆角：`rounded-lg` (8px)，去除过于圆润的 16px，显得更专业干练。
  - 边框：`1px solid var(--border-subtle)`。
  - 背景：`var(--bg-surface)`。
  - 悬浮反馈（Hover）：卡片不产生大幅度的上浮位移或刺眼发光，仅发生 **边框颜色微加深 + 背景微提亮 + 右上角微操作图标淡入**。
- **图标展示 (Icon)**：
  - 尺寸统一为 `26px × 26px`，采用单色 SVG 或抓取的真实网站高清 Favicon。
  - 图标底色为浅灰色圆角矩形，防止白底或异形图标破坏整体统一感。
- **路由数据行 (Route Info Footer)**：
  - 严格采用 `--font-mono` 等宽字体，字号 `11px`，颜色 `--text-secondary`。
  - 当命中内网最长前缀时：显示 `● 10.8.0.52 · 4ms`（4px 绿色实心微点）。
  - 当走公网备用时：显示 `○ gitlab.com · 35ms`（4px 灰色空心点）。

#### B. 悬浮展开与多入口切换 (Dropdown on Hover/Click)
当用户点击卡片右侧更多或展开时，向下平滑展开极简清单：
```
┌───────────────────────────────────────────────┐
│ ✓ ● 10.8.0.52 (内网机房A)         4ms  [默认]  │
│   ○ 192.168.1.100 (内网机房B)    12ms  [直达]  │
│   ○ git.company.com (公网VPN)    48ms  [直达]  │
└───────────────────────────────────────────────┘
```

### 5.4 分组与标签栏 (Groups & Tag Pills)
- **分组标题栏 (Group Header)**：
  - 采用 `14px` Semibold 标题，前面可带一个极简微图标或折叠指示符。
  - 右侧为一条平直的 `1px` 极细分割线贯穿至右边界，构成清爽的视觉隔断。
- **高频标签筛选条 (Tag Filter Pills)**：
  - 标签以纯文字小胶囊展现，默认字色 `--text-secondary`，悬浮时背景轻微灰底。
  - 激活态：深底高亮（黑底白字或白底黑字），`h: 26px`，`px: 10px`，字号 `11px`。

---

### 5.5 弹窗与抽屉规范 (Modal & Sheet Design)
- **遮罩层 (Backdrop)**：`bg-black/30 backdrop-blur-sm`，放弃 `bg-black/80` 的压抑深黑，保持背景隐约可见的透气感。
- **窗口容器 (Modal Container)**：
  - 宽度统一规范在 `480px ~ 560px` 阶梯档位，主弹窗容器必须设置**显式固定高度**（如 `h-[560px] flex flex-col`）。
  - **严禁自适应内容产生高度跳变**：多 Tab 切换、表单折叠展开、异步请求加载、错误信息出现等任何交互，弹窗外框尺寸必须 100% 保持绝对恒定，避免视觉突兀感。
  - 内部视口采用 `flex-1 overflow-y-auto` 消化动态内容。
  - 头部与底部取消粗厚的分界线，改用纯粹的内边距空间分割。
- **表单输入组件**：
  - 输入框高度 `36px`，底色 `var(--bg-subtle)`，无边框或单线极细框，聚焦时边框高亮。
  - 标签（Label）放在输入框上方，字号 `12px`，字重 `500`，字色 `--text-secondary`。
  - 多入口配置列表：采用极简条目卡片排版，点击“+ 添加入口”新增一行，内网/外网自动探测打标。
- **书签导入分组策略 (3 种目标分组模式规范)**：
  1. **按原路径设置分组名 (Path-based Grouping)**：自动解析 Chrome 导出的 HTML 书签树或浏览器书签目录层级，保留/自动创建同名分组。
  2. **指定固定分组 (Specified Group)**：
     - **约束**：**下拉选择器必须严格过滤掉「常用」与「未分组」**。
     - **原理**：「常用」为使用频率最高的动态聚合组，「未分组」为无归属书签的自动计算组；指定分组仅支持用户自定义创建的具体分组。
     - **交互**：若用户暂无任何自定义分组，给予提示引导前往偏好设置创建或改用路径/未分组策略。
  3. **存入未分组 (Ungrouped)**：直接归入系统默认的「未分组」中。

### 5.6 提示反馈 (Toast & Empty States)
- **极简 Toast**：
  - 触发智能跳转时，在屏幕底部中央弹出极简单色提示胶囊：
  - `⚡ 内网直达: 10.8.0.52 (4ms)`，停留 1.5 秒后静默淡出。
- **空状态 (Empty State)**：
  - 无繁复插画，仅居中放置单色极简线框图标 + 一行 13px 提示文字 + 醒目的小胶囊操作按钮。

### 5.7 自适应表单选择器规范 (Adaptive Form Select & Segmented Control)

针对弹窗表单（设置、书签新增/编辑、导入迁移、Popup）中的单项选择控件，**彻底废除浏览器原生 `<select>` 标签**（原生下拉菜单在跨系统下无法换肤、黑白对比失调且无法展示微标），统一实施**智能自适应选择器体系**：

#### A. 选项计数自适应判定规则 (The Adaptive Threshold Rule)
- **当选项数 $N \le 2$ 时（二选一/开关型）**：
  - **采用形态**：**iOS/macOS 风格极简分段胶囊 (Segmented Control)**。
  - **设计目标**：**零下拉层级、单次点击直接切换**。选项全部平铺在带有 `bg-subtle` 的浅底凹槽内，当前选中项呈现浮起卡片质感 (`bg-surface` + 微弱投影 `shadow-sm`)。
  - **典型应用**：时钟制式（`24 小时制` vs `12 小时制`）、布尔策略开关。
  ```text
  时钟制式 (N=2):
  ┌───────────────────────────────┬───────────────────────────────┐
  │     ● 24 小时制 (14:30)       │        12 小时制 (02:30)      │
  └───────────────────────────────┴───────────────────────────────┘
  ```

- **当选项数 $N > 2$ 时（多选项/动态列表）**：
  - **采用形态**：**Linear / Raycast 风格极简卡片弹出选择器 (Custom Popover Select)**。
  - **设计目标**：**主题 100% 深度融合、支持图标/徽标与精密勾选状态**。
  - **交互特征**：
    1. **触发器 (Trigger)**：高度 `36px`，`bg-subtle` 底色 + `1px solid var(--border-subtle)`，右侧为顺滑翻转的微型指示箭头（展开时平滑旋转 180°）。
    2. **下拉卡片 (Popover)**：`bg-surface` 实体背景 + `var(--shadow-popover)` 柔和弥散阴影，`border-radius: 10px`。
    3. **条目设计 (Item)**：支持左侧图标/色彩微标展示，当前选中项右侧显示单色勾选图标（`✓`），鼠标悬停呈现 `bg-subtle` 平滑过渡。
    4. **失焦关闭**：点击页面空白外部区域或按下 `Esc` 键时即刻平滑收起。
  - **典型应用**：所属分组选择（多分组）、默认主搜索引擎选择（百度/谷歌/必应/DuckDuckGo）、目标导入分组等。
  ```text
  默认主搜索引擎 (N=4):
  ┌─────────────────────────────────────────────────────────────┐
  │ 🌐 谷歌 (Google)                                          ▾ │
  └──────────────────────────────┬──────────────────────────────┘
                                 │ ┌──────────────────────────┐
                                 │ │   ● 百度 (Baidu)         │
                                 │ │ ✓ 🌐 谷歌 (Google)     ✓ │
                                 │ │   ⚡ 必应 (Bing)          │
                                 │ │   🦆 DuckDuckGo          │
                                 │ └──────────────────────────┘
  ```

## 6. 交互动效与微反馈 (Motion & Micro-interactions)

极简风格排斥一切拖泥带水的花哨动画，所有动效以“**干脆、轻盈、物理直觉**”为准则：

1. **状态过渡时间 (Duration)**：
   - 按钮悬浮、颜色切换：`120ms ease-out`
   - 下拉菜单展开、Toast 提示：`160ms cubic-bezier(0.16, 1, 0.3, 1)`
   - 弹窗呼出：`200ms cubic-bezier(0.16, 1, 0.3, 1)`（伴随微小的 `scale(0.98 -> 1)` 物理形变）
2. **拒绝动画干扰**：
   - 状态呼吸灯**不再常驻剧烈缩放放大**，改用纯色静态显示或极其轻微的透明度脉冲（0.7 -> 1.0），避免新标签页看起来像闪烁的广告牌。
3. **快捷键系统**：
   - `/` 或 `Ctrl/Cmd + K`：聚焦搜索框
   - `Esc`：关闭任何打开的弹窗 / 取消搜索聚焦
   - `Enter`：当有书签匹配时跳往最优地址；无匹配时调起外部搜索引擎
