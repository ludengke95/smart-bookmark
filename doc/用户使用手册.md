## 1. 快速安装与初始设置

1. **安装插件**：在 Chrome 或 Edge 扩展管理页面中加载本扩展。
2. **设为新标签页**：安装后，打开新标签页（`Ctrl + T` 或 `Cmd + T`），即可看到极简清爽的智能书签仪表盘。
3. **固定到工具栏（推荐）**：点击浏览器右上角拼图图标 🧩，将 **Smart Bookmark** 固定在工具栏，方便随时通过 Popup 弹窗搜索和访问。

---

## 2. 日常使用：新标签页与快捷访问

### 2.1 聚合搜索框
- **本地书签即时检索**：在顶部搜索框中输入关键词，系统会立即匹配书签**名称、URL 网址、所属标签**，匹配结果会高亮展示。
- **网络搜索**：点击搜索框左侧的图标可切换搜索引擎（Google / Bing / 百度等）。输入关键词后直接敲击回车键 `Enter`，即可快速发起网络搜索。

### 2.2 标签多选过滤
- 搜索框下方展示了您的常用标签，按使用热度排序。
- 点击标签可进行过滤；支持**多选标签**进行交集筛选。

### 2.3 一键直达与状态感知
- **直接点击卡片**：插件会自动挑选当前网络下最快可达的入口为您打开页面。
- **悬停预览**：鼠标悬停在书签卡片右上角的网络状态指示灯上，可查看当前匹配到的最佳 URL 及连通状态。

## 3. 多维排序：灵活的书签排布规则

在新标签页主页中，标签筛选条的右侧提供了**排序方式切换器**。系统支持以下 5 种排序规则，满足不同场景下的查找习惯：

| 排序模式 | 图标 | 适用场景与排序逻辑 |
| :--- | :---: | :--- |
| **↕ 自定义排序 (默认)** | `↕` | **支持自由拖拽**。允许用户在分组内或跨分组直接拖动书签卡片调整顺序。 |
| **🔥 按访问热度** | `🔥` | 根据书签的**历史点击频次**从高到低自动排序，高频使用的工具自动靠前。 |
| **🔤 按书签名称** | `🔤` | 按照书签名称的**拼音/字母顺序（A-Z）**自然排序，方便按名称首字母快速检索。 |
| **⚡ 按响应测速** | `⚡` | 优先展示**可达且响应延迟极低（极快/良好）**的书签，不可达项自动排至最后。 |
| **🕒 按添加时间** | `🕒` | 按照书签的**创建录入时间（最新优先）**倒序排列，快速找到最近收藏的站点。 |

> 📌 **拖拽排序提示**：
> 只有在 **「↕ 自定义排序」** 模式下，且当前未处于全局搜索或标签过滤状态时，才支持在主界面直接拖动书签卡片进行排序及跨分组迁移。

## 4. 核心功能：添加与配置多入口书签

这是 Smart Bookmark 最强大的功能，特别适合拥有内外网多入口的应用系统。

### 3.1 添加新书签
1. 点击顶部导航栏的 **「+ 添加书签」** 按钮。
2. 输入 **书签名称**（例如：`公司 GitLab` 或 `家庭私有云 NAS`）。
3. **配置多个访问地址（Endpoints）**：
   - 地址 1（内网）：`http://192.168.1.100:8080`（处于内网环境时将自动优先走此地址）
   - 地址 2（公网域名）：`https://git.mycompany.com`（不在内网时自动回退至公网入口）
   - 可点击 **「+ 添加更多地址」** 继续补充更多备用地址或子网 IP。
4. **选择图标**：
   - 系统会自动抓取第一个地址的站点图标（Favicon）；
   - 也可点击图标选择器，直接搜索调用内置的品牌图标库（如 GitLab、Jenkins、Docker 等 3000+ 品牌 Logo）或通用分类图标。
5. **选择分组与添加标签**：选择所属分组，输入标签（输入后按回车添加）。
6. 点击 **「保存」** 完成创建。

> 💡 **智能工作原理解析**：
> 当您身处公司或家中时，插件通过局域网探测感知到当前内网环境，自动匹配网段最相近的内网 IP 直连；当您出差或在外办公时，内网地址不可达，插件毫秒级感知并自动为您切换至公网域名。

## 5. 高效管理：分组与标签系统

### 5.1 系统三大分组类型
1. **⭐ 常用（动态内置组）**：
   - 系统根据您的实际点击使用频率自动计算，最常用的书签会自动排在这里，无需手动维护。
2. **📁 自定义分组**：
   - 您可以根据工作项目、业务领域自由创建的分组（如 `日常工作`、`DevOps 工具`、`开发文档`、`娱乐生活`）。
   - 在设置中支持自定义拖拽排序和默认展开/折叠。
3. **📦 未分组（自动兜底）**：
   - 凡是没有显式指定分组的书签，都会整齐归拢在未分组中，避免任何书签遗失。

### 5.2 卡片管理与拖拽
- 鼠标悬停在卡片上，点击卡片右上角的 **「...」** 或操作按钮，可快速进行 **编辑**、**删除** 或 **复制地址**。
- 支持点击分组标题右侧的折叠箭头，快速收起或展开该分组。

## 6. 导入与去重：一键迁移浏览器书签

无需手动繁琐录入，轻松将浏览器原有收藏一键迁移至 Smart Bookmark：

1. 点击顶部导航栏的 **「📥 导入」** 打开导入面板。
2. 系统会自动读取您当前浏览器的书签树。
3. **配置导入策略**：
   - **保留原目录层级作为新分组**：自动将浏览器中的文件夹转换为自定义分组；
   - **存入未分组**：将导入的内容暂时归拢至未分组，后续统一整理；
   - **导入至指定分组**：将勾选的书签全部导入到您现有的某个自定义分组中。
4. **智能重复标记**：
   - 系统会自动比对网址与名称，高亮提示**疑似重复**的书签，您可以按需取消勾选，防止重复导入。
5. 点击 **「确认导入」** 即可。

## 7. AI 智能整理：让书签井井有条

当积累了大量书签后，借助 AI 可以在几十秒内完成全局重分类、自动归纳标签与清理冗余。

点击顶部导航栏的 **「✨ AI 整理」** 按钮，系统提供两种灵活的整理方式：

### 方式一：网页大模型免 Key 模式（推荐，完全免费）
无需拥有 OpenAI/API Key，使用您日常习惯的 ChatGPT、Claude、Kimi、DeepSeek 网页版即可：
1. 打开 AI 整理弹窗，进入 **「网页大模型（免 Key）」** 区域。
2. 点击 **「复制提示词与数据」**，系统会自动打包您的书签清单与预设结构化 Prompt 到剪贴板。
3. 切换到任意网页大模型对话窗口，直接粘贴并发送。
4. **获取整理结果并导入（支持两种导入方式）**：
   - **方式 A：直接粘贴文本**：复制 AI 回复中的 JSON 代码块，粘贴进插件弹窗的文本框中；
   - **方式 B：上传 JSON 文件**：若 AI 回复生成了 `.json` 结果文件或您将结果保存为了文件，可直接点击 **「选择文件」** 或拖拽上传该 JSON 文件。
5. 点击 **「解析并预览」**，检查 AI 为您规划的分组结构、标签分类与新增/合并建议。
6. 确认无误后点击 **「应用整理结果」**，全量书签瞬间分类就绪！

### 方式二：API 自动化直连
1. 在设置中填入您的 API Key 及 Base URL（支持 OpenAI 规范接口、DeepSeek 等）。
2. 在 AI 整理面板点击 **「一键自动分析」**，系统将在后台自动交互并直接展示整理方案供您确认。

## 8. 数据备份与安全恢复

所有书签数据均存储在您的本地浏览器中。为了保障数据安全或实现跨设备迁移：

1. 点击顶部导航栏的 **「💾 备份与恢复」**（或通过设置页面进入）。
2. **导出备份**：点击 **「导出 JSON 备份」**，将全量书签数据、分组配置、使用统计下载保存为本地 `.json` 文件。
3. **导入恢复**：更换电脑或重新安装浏览器时，点击 **「导入备份文件」**，选择之前的 JSON 备份即可完整还原所有内容。

## 10. 常见问题与排查 (FAQ)

**Q1：为什么我配置的内网地址显示无法访问或跳转到了外网域名？**  
**A**：Smart Bookmark 会实时探测连通性。如果当前设备未连接到该内网 WiFi、未开启对应 VPN，或者该内网服务端口关闭，系统会自动判定该地址不可达，并安全降级跳转到您配置的可用外网地址。

**Q2：我的书签数据会被上传到云端服务器吗？**  
**A**：绝不会。Smart Bookmark 遵循严格的 Local-First 纯本地隐私原则，所有书签条目、地址与点击统计仅存放在您本机的 Chrome 本地存储中。

**Q3：我想修改某个书签在「常用」分组中的位置可以吗？**  
**A**：「常用」是基于您的真实点击频率由算法动态计算生成的，会随着您的日常使用自动调整。您无需花费精力手动排布，只需正常点击使用即可。
