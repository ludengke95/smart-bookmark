# 字体排版与网格标尺 (Typography & Spacing)

> 本文档为《前端设计规范》第 3 章拆分，详见 [前端设计规范.md](../前端设计规范.md)

## 3.1 字体栈定义

```css
/* 主界面字体：系统原生现代无衬线字体 */
--font-sans: -apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", Roboto, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;

/* 网络数据/时间/延迟/IP专用字体：严密对齐的等宽字体 */
--font-mono: "SF Mono", "JetBrains Mono", Menlo, Monaco, Consolas, "Courier New", monospace;
```

## 3.2 模块化字阶表 (Type Scale)

| 角色 (Role) | 字号 / 行高 | 字重 (Weight) | 字体族 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Clock** | `44px ~ 52px` / `1.1` | `200` (Ultralight) / `300` (Light) | Mono | 顶部中心极简数字时钟（纤细无压迫感） |
| **Heading 1** | `16px ~ 18px` / `1.4` | `600` (Semibold) | Sans | 分组大标题、弹窗主标题 |
| **Body (Card Title)**| `13px ~ 14px` / `1.4` | `500` (Medium) | Sans | 书签名称、主输入框文字 |
| **Caption (Subtext)**| `12px` / `1.3` | `400` (Regular) | Sans | 书签副标题、标签筛选按钮、座右铭 |
| **Data (IP & Metric)**| `11px` / `1.2` | `400` (Regular) | Mono | IP 地址、延迟数字（如 `10.8.0.52 · 4ms`） |
| **Micro Badge** | `10px` / `1.0` | `500` (Medium) | Sans / Mono | 内网/外网极简文字微标 |

## 3.3 间距网格系统 (Spacing & Grid)

系统基于 **4px / 8px 基础网格系统**：
- **微间距**: `4px` (gap-1), `8px` (gap-2) —— 图标与文本、徽章内边距
- **组件间距**: `12px` (gap-3), `16px` (gap-4) —— 卡片内边距、搜索框内边距
- **区块留白**: `24px` (gap-6), `32px` (gap-8), `48px` (gap-12) —— 分组与分组之间、Hero 区域与内容区域之间
