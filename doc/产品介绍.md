# 🌟 Smart Bookmark（智能书签与新标签页）产品介绍

> **Languages / 语言**: [English](./en/product-overview.md) | 简体中文

## 一、 产品诞生背景与解决的核心痛点

在日常研发、运维以及现代数字化办公场景中，工程师和重度网络使用者经常面临以下棘手问题：

### 1. 同一系统，内外网多入口混乱（最核心痛点）
很多常用服务（如 **GitLab、Jenkins、Grafana、Jira、私有知识库、NAS/自建网盘** 等）在不同环境下访问地址完全不同：
- **在公司/局域网内**：访问的是内部高速直连 IP（如 `http://192.168.10.20:8080`）；
- **在家/出差外网**：通过域名或公网端口映射（如 `https://git.company.com`）或者不同的 VPN 子网访问。

**传统书签的局限**：一个书签只能保存一个 URL。用户要么存两三个同名书签并靠肉眼猜测该点哪个，要么每次遇到超时卡顿后再手动改地址。

> **Smart Bookmark 的破局点**：提出 **「1 个书签身份 = N 个访问入口（Endpoint）」** 概念。插件感知当前所处网络，自动在后台探测连通性，并通过算法自动秒级直达当前网络下最快、最优的访问入口！

### 2. 浏览器书签层级深、查找繁琐、容易堆积成“数字废墟”
随着收藏内容增加，原生书签栏拥挤不堪，文件夹层级嵌套深，导致查找困难；手动整理数百上千条书签费时费力。

### 3. 数据隐私顾虑与视觉体验单调
第三方网络书签服务往往需要注册账号并将数据上传到云端，存在隐私与安全性顾虑；而浏览器自带的新标签页广告多或风格刻板，缺乏个性化与美感。

## 二、 核心功能与技术亮点

### 1. 🚀 多入口智能测速与精准直达（XOR 智能网络匹配）
- **多地址聚合管理**：每个书签支持绑定多个 URL（内网 IP、公网域名、备用节点等）。
- **32 位二进制 IP XOR 算法匹配**：
  - 自动识别客户端本机局域网 IP（基于 WebRTC 本地探测）；
  - 将内网 IP 转换为 32 位二进制，通过按位异或（XOR）精准计算与本机 IP 的**最长公共前缀**，优先选择与当前处于同一网段/最近子网的地址。
- **可达性探测与保险复验机制**：
  - **按需触发**：浏览器启动或网络环境变化时自动探测连通性并缓存结果，毫秒级即开；
  - **点击复验与故障顺位降级**：点击书签瞬间快速复验，主入口不可达时自动顺位降级到备用入口，告别白屏超时。

### 2. 🤖 多模态 AI 智能书签整理与分类
- **网页大模型免 Key 模式（零成本）**：一键生成结构化整理提示词，用户直接复制到 ChatGPT、Claude、Kimi、DeepSeek 等任意网页大模型，粘贴返回的 JSON 即可一键完成全量书签分类与标签归纳。
- **API 直连模式**：支持配置 OpenAI / DeepSeek / 兼容接口的 API Key，一键自动化整理。
- **MCP (Model Context Protocol) 扩展**：支持与本地 AI 智能体/模型上下文协议无缝联动。

### 3. 🎨 极简美学新标签页与多维管理
- **三套优雅主题预设**：Ceramic Light（素白陶瓷）、Obsidian Dark（黑曜暗夜）、Paper Sand（暖沙质感），自适应舒适排版。
- **多维分类体系**：
  - **「常用」动态高频组**：根据用户点击频次与周期自动计算，置顶呈现；
  - **「自定义分组」**：自由创建、拖拽排序与折叠；
  - **「未分组」**：未归类书签自动兜底聚合；
  - **「多选标签（Tags）」**：支持按热度排序与多标签联合筛选。
- **全能聚合搜索**：搜索框同时支持即时本地书签搜索与一键回车调用 Google、Bing、百度等主流搜索引擎。

### 4. 🔒 纯本地安全架构（Local-First）
- 数据 100% 存储于本地浏览器（`chrome.storage.local`），无需注册登录，零数据上传。
- 提供完整的一键 JSON 导入、导出与备份还原能力，数据资产完全由用户掌控。

## 三、 技术栈概览

- **扩展框架**：WXT (Next-gen Web Extension Framework) + Chrome Manifest V3
- **前端架构**：Svelte 5（Runes 响应式系统）
- **样式与设计**：Tailwind CSS + 统一色彩 Token 规范
- **图标系统**：Simple Icons（3000+ 品牌 Logo 离线支持）+ Lucide Icons（通用功能图标）
